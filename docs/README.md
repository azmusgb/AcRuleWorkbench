# FW Editor Viewer documentation

This package is focused on the read-only FW Editor-style browser surface.

Primary entry points:

- `README.md` — run and validation instructions
- `README_FW_EDITOR_VIEWER_V83.md` — v83 startup/readiness fix notes
- `docs/formworks-editor-ac-reference-guide.md` — compact AC/FW Editor terminology reference

The default UI avoids diagnostic-dashboard framing. Advanced diagnostic surfaces are hidden unless the viewer is opened with `?advanced=1`.
